# 面试演示脚本（5 分钟主线）

> 目标：5 分钟内让面试官看到"完整业务闭环 + 合规引擎 + AI 协作工程"三个记忆点。
> 原则：每一步只讲一句话卖点，细节留给追问——**演示是钩子，追问才是你的主场**。

## 演示前准备（10 分钟）

- [ ] 后端启动：`cd backend && ./run.sh`（确认 `GET /api/health` 返回 UP）
- [ ] 前端启动：`cd frontend && npm run dev`
- [ ] 浏览器开两个隐身窗口：窗口 A 登录 `admin/admin123`（ADMIN），窗口 B 登录审批角色（APPROVER，见 V13_1 初始化）
- [ ] 预置数据检查：至少 1 个供应商、1 个客户、2 个商品、1 个仓库已有首营通过记录（首次启动 DataInitializer 会初始化账号与权限）
- [ ] 可选：本地起 Redis（jti 黑名单完整生效）；不起也能跑（降级放行，可主动讲这个设计）

## 5 分钟主线（每步：操作 → 一句话卖点）

### 1. 登录 + 工作台（30s）
以 admin 登录 → 落地在工作台。
> **卖点**："登录后不是空白页而是待办驱动——待审批数、近效期批次、证照到期一目了然，GSP 红线不是靠人肉巡检。"

### 2. 采购下单 → 提审（60s）
采购订单 → 新建（远程搜索供应商/商品）→ 加明细 → 保存 → **提交审批**。
> **卖点**："提审时信用/首营校验已在后端状态机里跑过一遍——审批是事前控制不是事后留痕。"
顺带点开主数据列表的"显示停用"开关：
> **卖点**："主数据只软删除，被单据引用的删不掉——GSP 不允许物理删除，作废红冲才可追溯。"

### 3. 切窗口 B：审批（45s）
以 APPROVER 登录 → 审批中心 → **展开行明细**（商品/数量/单价）→ 驳回试一次（必填意见）→ 重新提交 → 通过。
> **卖点**："金额分级审批按 bizType+金额路由 L1/L2；审批人≠制单人是后端强制的，不是靠自觉。"

### 4. 采购入库——故意触发一次校验（60s）
切回窗口 A → 采购入库 → 选刚审批的订单 → **效期故意填成早于生产日期** → 保存被 400 拦截 → 改对 → 保存成功。
> **卖点**："批号/效期/检验单号是入库三强制，效期逻辑前后端双层校验——这是 GSP 红线 R2 的入口。"

### 5. 销售出库——FEFO 事前预览（60s）
销售出库 → 选订单（自动带出明细）→ 选仓库 → **展开明细行看批次分配预览**（FEFO 排序、效期标色、可售量）→ 把数量改到超过可售量 → 保存按钮变灰 → 改回 → 保存。
> **卖点**："FEFO 不是提交后才报错，是事前就能看到系统准备从哪个批次扣——操作员事前知情。"

### 6. 批次追溯（45s）
追溯查询 → 输入刚入库的批号 → 正向（流向客户）+ 逆向（来源供应商）。
> **卖点**："药品召回场景：任何批次 1 分钟内双向追溯；作废单据灰显，不污染真实流向。"

### 7. 财务闭环 + 审计（30s）
财务 → 收款单核销刚生成的应收 → 状态 UNSETTLED→SETTLED → 系统管理 → 审计日志看刚才的操作留痕（含前后值 + IP）。
> **卖点**："出库自动生成应收、作废联动红冲；审计日志记录变更前后值——对账恒等式按业务日期分期。"

## 高频追问 Q&A（背下来）

| 追问 | 30 秒答法 |
|---|---|
| 并发怎么保证不超卖？ | FEFO 分配走 `FOR UPDATE` 行锁逐批扣减；批次首建用 `INSERT...ON CONFLICT` 原子占位；单号用 number_sequence 表，ConcurrentUpsertTest 有并发测试佐证 |
| 为什么单体不拆微服务？ | MVP 单体模块化：按业务域分包（10 个 package），事务边界清晰——出库+应收+流水在同一个本地事务里，拆开反而要做分布式事务 |
| 成本为什么用移动加权？ | 总账价值准（商品级）+ 批次级 unit_cost 留痕支持毛利分析；作废红冲按原单价回补，数学上对称，有测试验证 |
| AI 在这个项目里怎么用？质量怎么管？ | AI 生成代码，我做领域审查——三轮"审查→整改→核验"文档闭环，60+ 问题全部修复并有测试佐证；GSP 规则由我定，AI 不拍板业务（docs/reports 有完整审查记录） |
| Redis 挂了会怎样？ | jti 黑名单降级放行 + tokenVersion 兜底（禁用/改密仍即时踢下线），TokenBlacklistDegradationTest 专门测这条路径 |

## 演示避坑

- 后端没起 → 前端所有请求 502，先确认 8080
- 演示机分辨率 <1366 时弹窗可能贴边（已知限制，README 已声明；主动提比被问好）
- 如果面试官要看测试：`mvn test` 现场跑约 1 分钟，154 项全绿是最好的信任状
- 不要现场演示 Excel 导入/导出的大文件——慢且无卖点，一句"复用 EasyExcel 组件"带过
